# Dayflux

> **Dayflux — Fresh wallpaper, every day.**

开源、免费的 macOS 菜单栏应用：每天自动获取 Bing 每日壁纸，预览、保存到自选目录、设为桌面。代码采用 [MIT License](LICENSE)。

## 功能

- **每日壁纸**：获取当天 Bing 每日图片，支持标准高清与 UHD 超清；标题、生效日期与实际像素均来自真实数据。
- **预览与下载**：主窗口预览当日壁纸，可单独下载；同日文件已存在时默认跳过，覆盖前逐次确认；写入采用临时文件 + 原子移动，不产生半截文件。
- **设为桌面**：应用到所有已连接显示器，并回读确认壁纸确实生效。
- **自动化**：可设定每日时间，常驻时按点自动下载／更换；失败 5 分钟重试，成功后当天不重复；开机或唤醒后按当天补偿一次。
- **菜单栏**：左键图标直接打开主窗口，右键打开快捷菜单；可关闭菜单栏图标，改从访达／启动台双击打开。
- **清洁键盘**：一键临时禁用整个键盘（含 F1–F12、亮度、音量等系统键），鼠标保持可用，点「结束清洁」解除。
- **轻量隐私**：无账号、无上传、无数据库、无下载历史；偏好只存在本机。

## 系统要求与安装

- macOS 27.2 或更新版本（Apple Silicon 已验证）；从源码构建需要 Xcode Command Line Tools，不需要 Xcode.app，也不需要 Apple Developer 账号。
- **预编译包**：从 [GitHub Releases](https://github.com/kingdocs/dayflux/releases) 下载 `Dayflux-2.0.0-macos.zip`，解压后把 `Dayflux.app` 拖入 `/Applications`，双击启动。
- 预编译包为自签名、**未经 Apple 公证**。首次打开请右键「打开」，或在「系统设置 → 隐私与安全性」中允许；更推荐从源码自行构建签名（见下节）。
- 应用为 `LSUIElement` 类型，**不进 Dock、启动不弹主窗口**，只驻留菜单栏；左键点图标调出主界面，关闭主窗口不会退出应用。

## 从源码构建

```bash
git clone https://github.com/kingdocs/dayflux.git
cd dayflux
DAYFLUX_SIGN_MODE=adhoc ./build.sh
open build/Dayflux.app
```

第三方请使用 `DAYFLUX_SIGN_MODE=adhoc`：仓库不分发签名私钥，默认 `./build.sh` 会因缺少证书密码而退出。若想使用自己的签名身份，可用 `signing/create_selfsigned.sh` 生成证书（等价于换一个应用身份），详见 [signing/README.md](signing/README.md)。

`build.sh` 用 `swiftc` 编译 `Sources/*.swift`，组装 `.app`、`plutil -lint` 校验，最后签名并做严格校验；产物为 `build/Dayflux.app`，重复构建只覆盖该 bundle。

## 首次使用

1. 启动后点菜单栏图标打开主界面，首次会提示选择壁纸保存目录，默认建议 `~/Pictures/Dayflux`。
2. 目录授权只作用于你选择的这一个路径。应用**不会**迁移、重命名或删除目录里的任何已有文件。
3. 需要「清洁键盘」功能时，按系统提示授予辅助功能权限；授权缺失时该按钮会给出提示，不影响其它功能。

## 界面与操作

| 区域 | 行为 |
|---|---|
| 预览 | 16:9 展示当日壁纸；加载中／失败有独立状态与「重试」，预览失败不影响下载 |
| 辅助信息 | 壁纸标题、`Bing · 生效日期 · 实际像素`，像素取自下载后解析结果 |
| 设置桌面 | 必要时先下载成品，再应用到所有已连接显示器 |
| 下载壁纸 | 同日同地区文件已存在时默认跳过；覆盖前弹窗确认 |
| 打开目录 | 在访达中显示成品文件（不存在则显示目录） |
| 清洁键盘 | 全屏遮罩期间禁用键盘，点红色按钮解除 |
| 设置入口 | 点击主窗口的设置行，打开设置面板 |

设置面板为**上下单列**布局，宽 430pt、一屏完整显示、无滚动条；6 组设置依次为菜单栏图标、清晰度、自动下载与保存目录、定时更换、通知与登录启动、缓存清理。每组说明由首行控件旁的 `?` 图标承载，顶部「完成」按钮始终可见，也支持 Esc 关闭。

## 自动化说明

- 常驻期间用单次定时器挂到下一次执行时刻，而不是每分钟轮询；每天主线程最多唤醒 1～2 次。
- `lastRunDate` 只在「元数据获取 → 下载 → 设置桌面」全部成功后写入；任一步失败则当天保持未执行状态，5 分钟后自动重试。
- 冷启动延后 10 秒、系统唤醒延后 15 秒再补跑，避开系统桌面尚未就绪的窗口。
- 调度判断抽为纯函数 `SchedulePolicy.shouldRun` 与 `SchedulePolicy.nextFire`，位于 `Sources/Models.swift`，由冒烟测试覆盖。
- 关机、睡眠或强制退出期间无法保证准点；恢复运行后按当前日期补偿一次，**不追溯多日**。
- 登录启动通过 `SMAppService` 注册，可在设置面板开关；注册失败只提示一次。

## 文件与隐私

| 内容 | 位置 | 说明 |
|---|---|---|
| 壁纸成品 | 自选目录，默认 `~/Pictures/Dayflux` | 命名 `Dayflux_<日期>_zh-CN.jpg`，日期取 Bing 生效日 |
| 图片缓存 | `~/Library/Caches/Dayflux` | `dayflux_` 前缀，仅用于预览与重试；目录被系统清理后会自动重建；写失败只降级为纯内存，不影响下载与换桌面 |
| 偏好设置 | 本机 `UserDefaults` | 仅保存目录、时间、开关等，不含账号凭据 |
| 诊断日志 | 本机 `/tmp` | 记录网络、调度与状态项事件，不上传、不入仓库 |

「清理应用缓存」只删除缓存目录下本应用创建的文件，**绝不触碰壁纸保存目录**。应用不联网上报任何数据。

## 图片来源与使用边界

- 每日壁纸来自 Bing 每日图片接口，接口自带「**仅限用作桌面壁纸**」声明；图片版权归原权利人（微软及其图片提供方）所有。
- 本仓库与发行包**不打包任何壁纸图片**。程序只在运行时按该声明把图片下载到使用者本机，用作桌面壁纸；不随代码再分发，也不用于商业宣传。
- README 与文档截图中的壁纸缩略显示仅作界面说明，不作为图片素材提供。
- 该接口属非正式使用方式，随时可能变化；服务层已做协议隔离。

## 版本号

- 当前版本 **2.0.0**，为本项目的**首个公开发布版本**。
- 三段语义化规则：第 1 位用于新增功能或大的功能性升级，第 2 位用于小的功能性调整，第 3 位**只在纯 BUG 修复时**变更。
- 主界面右下角页脚形如 `V2.0.0(20261115.4)@Micheas`：软件版本、构建日期与当天第几次成功编译、作者署名。
- 版本号在 `build.sh` 顶部 `APP_VERSION`、署名在 `AUTHOR_TAG`；构建序号由脚本按当天成功次数自动累加（跨天归 1，失败不计数），存于不入库的 `.buildcounter`；`build/generated/BuildInfo.swift` 由脚本生成，页脚与 `Info.plist` 使用同一份值。
- 各版本发布说明见 [GitHub Releases](https://github.com/kingdocs/dayflux/releases)。

## 代码签名

- 预编译包用维护者本机的自签证书 `Dayflux Code Signing` 签名。签名脚本使用临时钥匙串，签完即删，不改动登录钥匙串或系统信任设置；`codesign --verify --deep --strict` 通过。
- **私钥与密码不入库、不随仓库分发**（见 `.gitignore`）；丢失后重新生成证书等于换一个应用身份，已授予的系统权限需重新授权。
- 自签的固有限制：无 Apple 签发链、TeamIdentifier 为 `not set`、`spctl -a` rejected、不能公证。这不是代码缺陷。
